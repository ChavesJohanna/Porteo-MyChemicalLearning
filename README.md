## Controles
- **Mover al personaje:** Teclas A-D
- **Saltar:** Tecla Espacio
- **Interactuar:** Tecla E
- **Disparar:** Clic Izquierdo
- **Abrir inventario:** Tecla Q
- **Asignar elementos del inventario al atajo:** Clic Izquierdo en el inventario -> Clic Izquierdo sobre el atajo

## Versión del motor
- **Motor:** Unity
- **Versión exacta:** 6000.3.11f1
- **Plataforma de desarrollo:** Android
- **Plataforma objetivo:** Windows

## Cómo abrir y jugar

1. Descargar o clonar el repositorio del proyecto
2. Ejecutar el archivo MyChemicalLearning.exe
3. Disfrutar
